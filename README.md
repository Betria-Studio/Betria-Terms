# BetriaProject - 規約・ポリシー管理リポジトリ（Betria-Terms）
本リポジトリは、**BetriaProject にメンバー（運営・開発・スタッフ等）として参加・参画する方**を対象とした、基本規約およびプライバシーポリシーの正文・原本を管理・公開するための公式リポジトリです。   
※Betria Project 傘下の各種サービス（Betraサーバー等）を利用する一般のプレイヤー・サービス利用者（エンドユーザー）向けの個別規程ではありません。

## 有効な規約の参照方法（重要） 
* **現在有効な規約・ポリシー**   
  GitHubの[**Releases / Tags**](../../tags)で公開されている**最新のバージョンタグ（例: `v1.0.0`）が付与されたファイル** が、現在有効な正文（原本）となります。
* **`main` ブランチおよび過去のタグについて**   
  `main` ブランチ（作業中ドラフト）および過去のバージョンタグは、改定作業や履歴参照用であり、現行の確定効力を示すものではありませんのでご注意ください。
